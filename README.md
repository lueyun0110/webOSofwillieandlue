# webOSofwillieandlue
webOS of willie and lue (not just a website!!!!)
  
  This webOS is designed for my ocs, willie and lue!! Specifically, who they are and their adventures!! To begin, I added three files: .html, .css, and .js (javascript). For the HTML part, I added the background, top handles with an ongoing time (used javascript within the HTML using <script>) and a clickable button to reopen the welcome window. then, i added the welcome window, which is shown when you open the webOS. after, the lue and willie apps were created with an image, stored info about themselves (who they are, fun fact, q&a section). then, there is the adventure log, which documents their recent adventures (yes, these are all of my drawings!!).
all of this was functioned with javascript (opening, closing, moving the windows and app icons) and css as design (mostly the boarders, colors, placement of the windows, apps, top and bottom handles, text, and background).
